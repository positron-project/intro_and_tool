# 文案风格指南（Club OS）

入口页（`#/home`）是给新生和合作方看的第一屏，措辞直接决定"像不像学生自己做的"。
这份文档约束**所有面向访客的中文文案**（页面正文、按钮、卡片、空状态、后台提示里的公开文案）。

## 三条硬规则

1. **写事实，不写情绪。** 每一句都要能被核对：人数、届次、项目数、时间、地点、工具名。
   - ✅ `60+ 个项目存档` `5 届没断过` `每周三 19:00 在 A 栋 302`
   - ❌ `丰富你的大学生活` `成就更好的自己`
2. **主语具体。** 用"你 / 我们 / 组里的谁"，不用"用户""大家"这类无人称。
   - ✅ `加群后先领一份学习路线，再挑一个项目跟着做。`
   - ❌ `为用户提供全方位的成长路径`
3. **说人话。** 同门学长学姐的口吻，不是客户经理口吻。一句话读出来不拗口就直接用。

## AI 味清单（出现即改）

| 别写                                             | 换成                                     |
| ------------------------------------------------ | ---------------------------------------- |
| 赋能 / 助力 / 打造 / 一站式 / 闭环 / 生态 / 矩阵 | 直接说做了什么：`带 4 届新人做项目`      |
| 让知识持续发生 / 开启技术之旅 / 探索无限可能     | 具体动作：`每周一次分享，讲完当场写代码` |
| 沉浸式 / 极致 / 全新升级 / 深度赋能              | 删掉形容词，留名词和动词                 |
| 不仅仅是 XX，更是 XX                             | 拆成两句实话                             |
| 我们致力于……                                     | 直接写做了什么                           |
| 携手 / 共创未来                                  | 说下次活动的时间地点                     |

其它要避免的：连续三个四字词语堆叠、每句都以"我们"开头、把简单名词写成缩写（除非组内确实这么叫）。

## 语气参考（本站已有的好句子）

- `学点技术 / 做点东西` —— 入口页主标题，四个字一句，动宾清楚
- `把经验传给下一届` —— 具体、可执行
- `按自己的节奏选择课程、资源和项目，不记录个人完成度。` —— 主动交代边界，反而可信
- `成员资料会同步到小组风采和项目协作卡片。` —— 说后果，不喊口号

## 长度与结构

- 入口页主标题：两行，每行 4–6 个汉字，不要折行到第三行。
- 入口页副标题/说明：**≤ 40 字**，一句话说完，句号结尾。
- 卡片标题 ≤ 14 字；卡片描述 ≤ 2 行（约 40 字）。
- 按钮：2–6 字动宾短语（`加入我们`、`打开工作台`、`查看全部`），不用"点击这里"。
- 空状态：先说明为什么空，再给出下一步动作（`还没有投稿。登录后可以提交面经。`）。

## 排版约定

- 中文正文用全角标点；中英文之间留一个半角空格（`用 Figma 画低保真`）。
- 数字与单位之间不留空格（`60+`、`5 届`、`19:00`）。
- 栏目小标签（eyebrow）用英文大写，字数 2–3 个词：`ABOUT US`、`LIVE WORKSPACE`、`ROUTE GUIDE`。
- 破折号用 `——`，一句话里最多一处。
- 感叹号最多一个，且只在真正的通知里用；正文默认句号。
- 专有名词大小写按官方写法：`Git`、`Figma`、`Python`、`MySQL`、`Cloudflare Turnstile`。

## 改文案的流程

1. 先写清这句话要让访客**做什么**（进群 / 看项目 / 报名 / 什么都不做只是知道）。
2. 写成一句事实句，再删掉所有形容词。
3. 读一遍：如果换成别的学校、别的社团也成立，说明太泛，回去补具体信息（数字、时间、地点、工具）。
4. 入口页文案改完**必须**在 1440 宽与 390 宽两档看一眼是否折行（`pnpm e2e` 里有一条标题不折行的断言）。
