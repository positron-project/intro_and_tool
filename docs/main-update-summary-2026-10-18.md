## 二、邮件和认证现状

- 邮件 API 仍为 `https://mail-api.twoword.cfd/api/v1/emails`。
- 默认发件人名称为“南航计算机科技小组”。
- 默认发件邮箱为 `no_reply@stcnchu.com`。
- 邮件验证码有效期为 10 分钟，发送冷却时间为 60 秒。
- 邮件正文使用独立 HTML 模板。
- 发送邮件和 Cloudflare Turnstile 校验通过线程池执行同步网络请求，避免阻塞异步事件循环。
- 本次整合保留独立的 Turnstile 配置文件，并增加 `TURNSTILE_ENABLED` 开关；关闭开关只用于本地调试，不删除密钥配置。

- 当前工作分支已包含 `origin/main` 最新提交 `b42ecda`。
