## 一、入口页档（当前生效）

### 定位

把首页第一屏当一张海报：**一个论点、一句话、一个强调色**。不靠装饰（网格、斜带、水印、十字标、假仪表、巨型英文轮廓字、刊物印记都已删除），海报感靠留白、字号层级与一条贯通细线立起来。

视觉关键词：`restrained poster / single accent / real campus line art / typographic hierarchy`。

唯一图像元素是真实校园线稿（`public/assets/campus/campus-line-art.png`）：首屏以右下 245px 圆形裁切出现，其余位置不铺图。

用色规则：暖白 / 纸白 / 暖墨阶 + 一套**深青蓝主色** token（管交互）+ 一套**琥珀强调色** token（管记号），再加一组**只属于校徽圆形标记的品牌蓝**（`--poster-brand` / `--poster-brand-hi`），没有别的颜色。品牌图形（`.site-brand-mark` 圆形标记、`.site-brand-college` 院校名矢量）**不再灰度化**：SVG 只当 CSS `mask`，颜色由 CSS 的 `background-color` 给——圆形标记取 `var(--poster-brand)`，院校名取 `var(--poster-ink)` 墨黑，因此图形永远不会再自带一份蓝。

> **2026-10：配色由「淡灰底 + 电光蓝」整盘换成「暖白底 + 深青蓝主色 + 琥珀强调色」（YG 指定）。** 三个角色各归其位：暖白 `#f9f5ed` 是纸底，深青蓝 `#0f4c5c` 管**可交互反馈**（CTA 实心面、hover、焦点环、进度线、条目 hover 底线、首屏柔光），琥珀 `#b3741a` 管**记号**（18×2 记号杠、导航当前项、03 选中项左杠、大号章节序号）。电光蓝 `#2b5cff` 退役的理由是它在暖白纸上偏冷偏脆，且「强调」与「交互」两义合一——现在交互认颜色、记号认颜色，一眼可辨。灰阶一并转暖（`--poster-ink` `#14110c` / `-2` `#4b443a` / `-3` `#857e73` / 线 `rgba(28, 22, 14, 0.14)`），否则中性灰落在暖白纸上会反出一层冷调。

> **2026-10：品牌图形由电光蓝改为院校官方 logo 的蓝。** YG 给了院校官徽参考图，实测主蓝 `#008cd6`、图标本体另有一档亮青 `#00a4e1`，于是抽成 `--poster-brand` / `--poster-brand-hi`；圆形标记吃一层 `225deg` 的青→蓝渐变复刻官方稿图标本体的过渡。代价要知道：校徽蓝比深青蓝浅，对暖白画布只有约 **3.4:1**（深青蓝 8.7:1），按无障碍的 logotype 例外处理，所以**除圆形标记以外的任何元素都不许借用这两个 token**。
>
> **同轮追加（YG 当场反馈）：院校名矢量改回墨黑 `--poster-ink`。** 参考图里院校名确实是蓝的，但 YG 要求站内品牌区只留圆形标记是蓝的、院校名回到黑；于是 `.site-brand-college` 单独覆一层 `background-color: var(--poster-ink)`，实测该区域蓝调像素归 0、最暗像素 `#111111`，同时圆形标记的蓝仍为 `#008cd6` 一系（顶带均值 `#1ea0dc`、底带 `#0990d7`）。

> **2026 改版：强调色由暖红 `#e8442a` 换成电光蓝 `#2b5cff`。** 退役理由是红同时兼任「强调」与「复制失败」，两义合一既让错误态抢眼，也让强调色失去专属性。现在错误态只走墨黑 + 文案。（电光蓝本身已于 2026-10 被上面的暖白 / 深青蓝 / 琥珀方案取代。）

### 首屏柔光背景（2026 新增）

首屏不再是「一块平底」：`.home-hero-viewport`（`src/components/home/hero-poster.css`）铺了一层**深青蓝柔光** —— 暖白纸右上角像有光斜着照进来，向左下衰减到零；暖底配冷光，正好把纸底的甜压住。

```css
background-image:
  url('/assets/home-hero-glow.webp'),                                                       /* 顶层：3KB 抗色带纹理 */
  radial-gradient(104% 48% at 84% 4%, var(--poster-accent-wash), rgba(15, 76, 92, 0) 68%); /* 下层：柔光本体 */
background-blend-mode: multiply, normal;                                                    /* 必须同层相乘 */
```

| 参数     | 取值                                                                | 理由                                                                    |
| -------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 方位形状 | 横椭圆 `104% 48%`，中心 `at 84% 4%`（屏内右上）                     | 中心若放到屏外（`86% -6%`）峰值就浪费在视口外，屏内只剩 6–14% 残余      |
| 峰值     | `--poster-accent-wash` = 深青蓝 18%                                 | 16% 看起来仍像没铺底；20% 是上限，再深就开始像「有底色」而不是「受光」  |
| 衰减     | 68% 处归零                                                          | 标题 / 正文 / 按钮全在左列（x 86–563），那里 alpha 已为 0               |
| 纹理     | `public/assets/home-hero-glow.webp`（1024px webp q72，**2984 字节**） | 见下                                                                    |

**那张 3KB 纹理不是装饰，是抗色带**：纯 CSS 渐变在 8bit 下会出现极长的同值段（实测穿过光斑的横向扫描线同值段 792px，等于整行一个灰值 = 肉眼可见硬色带）。把它乘上去后同值段缩到 **168px**、灰阶从 1 级变 4 级。纹理由生图云絮图（`viz/bg/` 过程稿）重映射到只剩 229–255 区间后导出。

**必须同层 `multiply`**：把不透明纹理当独立层压上去，会把整片光替换掉 —— 实测光斑核心 `#cbddff` → `#eff9ff`，页头「工具区」链接从 14.16:1 弹回 17.82:1，等于白做。

**三条硬界限**：峰值 ≤20%；只允许单层蓝（第二层配色试过青 / 暖白 / 雾紫，全部出局）；不做任何动画（没有 `@keyframes`，因此也不涉及 reduced-motion）。

实测代价（1440×900，这是文字列与光斑的真实关系，不是假想最坏值）：

| 位置                        | 基线  | 加光后 | 说明                                             |
| --------------------------- | ----- | ------ | ------------------------------------------------ |
| 首屏标题 `#111111`          | 18.88 | 17.77  | 光已衰减到 0                                     |
| 说明段 `--poster-ink-2`     | 8.86  | 8.59   | 同上                                             |
| 三级灰 `--poster-ink-3`     | 3.45  | 3.39   | 该灰本身就低于 AA 正文线，属既有状态，与本次无关 |
| 页头「工具区 →」（光斑核心）| 18.88 | 14.16  | 全页**唯一**被光覆盖的文字                       |

窄屏（`≤600px`）首屏会变成长于视口的滚动块，光重新对位成 `78% 34% at 76% 2%`（`hero-poster.css:57-64`），390×844 实测标题 17.03、工具区 14.51。

单文件版：`scripts/create-standalone.mjs` 会把 `/assets/home-hero-glow.webp` base64 内联进 `nchu-cs-club-standalone.html`（约 +4KB），不会丢背景。

### 动效与交互

一套运动语言，参数只有一份：`src/components/home/motion.ts`（秒）与 `hero-poster.css` 里 `.home-story-scroll` 上的 `--motion-*`（毫秒）必须同步改。

| 维度 | 值                             | 用途                                                   |
| ---- | ------------------------------ | ------------------------------------------------------ |
| 缓动 | `cubic-bezier(.16,1,.3,1)`     | 所有进场与 hover 回正（`EASE_OUT` / `--motion-ease-out`） |
| 缓动 | `cubic-bezier(.42,0,.58,1)`    | 退场专用（`EASE_IN` / `--motion-ease-in`），目前只给 05 的文章抽屉 |
| 时长 | 160 / 400 / 850 / 900ms        | 微交互 / 线条与面板 / 标题与段落 / 首屏整场             |
| 位移 | 4 / 16 / 24px                  | 图标按钮 / 文本 / 整块                                 |
| 交错 | 90ms                           | 同组按阅读顺序，单组总长 ≤240ms                        |

**签名动作（2026-10 新增）：线先落，字后到。** 每节眉标那条 2×18px 蓝杠先进场（400ms `scaleX` 生长，见 `poster-sections.css` 的 `.poster-eyebrow.is-rule-in::before`），节标题与承接句再按 90ms 交错跟上（`useRuleIn()` + `fadeUp()`）。每节顺序恒为：杠 → 标题 → 承接句 → 内容（04/05 是条目逐条跟进）。

**滚动反馈**：顶部 `.home-scroll-progress`（1px 进度线，`scaleX` 跟 `useScroll` + `useSpring`，`z-index: 120`，reduced-motion 下整条不渲染）；首屏依旧在 0.6vh–1.3vh 之间位移 + 缩放淡出离场（`ExpandedHomePage.tsx` 的 `HERO_PARALLAX_LIFT` / `HERO_PARALLAX_SCALE`），**柔光随首屏一起淡出**，所以不需要第二条滚动映射。

保留的动效还有：Lenis 平滑滚动、IntersectionObserver 驱动的当前节高亮、条目与按钮/链接的 hover 变色。`prefers-reduced-motion` 下走原生滚动、不渲染进度线、眉标杠直接给终态。

**2026-10 收敛**：02–06 的入场原来是同一套 `opacity + y`，但位移有 6 种值、交错有 7 种值、缓动常量在 5 个组件里各复制一份，而 `viewport.amount: 0.2–0.3` 会让快速滚动时标题与正文错帧到达。现在全部走 `motion.ts` 的 token；顺序差异靠「杠 → 标题 → 承接句 → 内容」的 90ms 阶梯表达，不再靠改 duration。

已删除：粒子 Canvas、点阵、流动线圈、十字定位标、假仪表读数、巨型英文轮廓字、刊物印记、成句的 SCROLL DOWN 标语（只剩左下角极简 `.scroll-indicator`）。加新动效前先判断它会不会让页面像 AI 生成的。

### 组件语言

- 校徽用圆形裁切资源 `college-logo-cropped.png`，不要用抽象图标替代学校识别资产。
- 导航用 Lucide 图标 + 短中文标签，当前项蓝色文字 + 底部 2px 指示线。
- 区块标题结构：等宽 eyebrow + 中文标题 + 右侧文本动作。
- 标签用 `6px` 圆角 + 浅色语义底，不做高饱和实心胶囊堆叠。
- 项目卡：头图（几何纹理 / 图标 / 短代码，不依赖照片）+ 状态 / 年份 + 标题 + 简介 + 技术栈 + 人数 / 星标。
- 成长卡：大号等宽数字 + 语义色图标 + 一条很弱的圆形装饰，数字优先。
- 名言卡：低对比度蓝灰渐变 + 衬线体，不做营销式引语。

### 动效与交互

| 位置     | 动效                        | 规则                                 |
| -------- | --------------------------- | ------------------------------------ |
| 页面切换 | `opacity` + 约 5px 垂直位移 | 约 `.18s`                            |
| 项目卡   | hover 上移约 3px            | 同时加强边框与阴影，键盘聚焦同样可见 |
| 按钮     | hover 上移约 1px            | 主按钮变深，次按钮加强边框           |

`prefers-reduced-motion: reduce` 下不做位移与持续动画；新动效遵守同一策略。

交互路径：门户 Hero「开始学习之旅」→ `#/learning`；「浏览项目库」→ `#/projects`；图标按钮必须有可读的 `aria-label` 或 `title`。

### 响应式

| 断点        | 规则                                                              |
| ----------- | ----------------------------------------------------------------- |
| `> 1240px`  | 公告 / 推荐项目 / 右侧状态栏三列，成长数据在主区底部              |
| `<= 1240px` | 门户外层单列，右侧面板横向三列                                    |
| `<= 900px`  | 导航折叠为菜单；Hero 单列；主区单列；右侧面板两列，名言卡横跨整行 |
| `<= 640px`  | 列表与卡片单列；推荐项目横向滚动；成长数据两列；底部操作纵向      |

移动端必须优先保留品牌识别、主标题、一个主要行动、进入门户的入口；次级状态文字、英文副标题、桌面导航可隐藏，但不能挤压内容或造成横向溢出。

### 内容语气

- 主叙事围绕「学习、构建、分享、传承」，避免「领先、赋能、全方位」这类营销词；文案细则见 `docs/copy-style.md`。
- 数字必须带含义（例如「04 代成员持续共建」），不要孤立展示增长数字。
- 行动按钮用动词：「开始学习之旅」「浏览项目库」「查看全部」。

### 复用边界

**应保持**：真实校园照片作为品牌锚点；深色入口页与浅色门户页的层级区分；蓝色主行动色 + 多色语义点缀；等宽技术标签；细边框、小阴影、适度圆角与列表分隔线。

**应避免**：用紫色或深色渐变替代现有蓝色系统；在所有区域同时堆叠蓝紫橙绿玫红；把门户页做成无层次的卡片墙；大面积模糊、过强发光、装饰性圆球或无数据含义的数字；没有明确操作结果的「了解更多」按钮。
