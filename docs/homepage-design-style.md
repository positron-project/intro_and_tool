# 首页设计风格与视觉规范

本文档提取当前首页的视觉语言和可复用规则，用于后续页面、组件和宣传物料保持一致。文档中的“首页”分为两个连续层级：

- `/home`：全景叙事首页（六部曲长卷，暖白纸面 + 深蓝图纸设计系统），负责建立品牌认同、介绍团队方向、展示实战成果并引导加入与探索。
- `/tools`：进入后的门户工作台，负责承载公告、项目库、学习路线、团队方向、资源库和成长数据。

## 设计定位

整体方向是“校园科技社区操作系统与工程图纸档案”：用真实校园线稿与点阵交互建立归属感与学术工科气质，用工程图纸信息层与代码卡片表达技术严谨性，用“学习 -> 实践 -> 传承”组织全站叙事脉络。

首页（长卷长屏）与门户页（高密度工作台）在保持核心品牌标识统一的同时，各有侧重：

| 层级 | 视觉性格 | 页面任务 |
| --- | --- | --- |
| 首页 `/home` | 暖白纸面（#FAF8F2）、深蓝工程墨水（#073F73）、校园线稿与点阵粒子交互 | 叙事性呈现科技小组全貌、双轨方向、实战沉淀与加群转化 |
| 门户页 `/tools` | 浅色、半透明面板、细边框、高密度数据卡片 | 让用户快速检索学习路线、开源项目、技术资源与通知公告 |

## 视觉关键词

`academic blueprint / engineering precision / warm ivory paper / deep tech navy / continuum / collaborative`

中文语境保持克制、专业、直接且充满行动力。大标题具愿景感，辅以精准的价值说明；CTA、标签、状态与规格说明均具备明确的跳转与操作指示。

## 字体和排版

- **主中文字体**：`MiSans`（小米自研专业排版字体），收敛为 3 个高频核心字重（Regular 400 用于正文、Bold 700 用于小标题与按钮、Heavy 800-900 用于巨幅主标）；本地按需加载并提供完备的系统字体栈回退（`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`）。
- **等宽工程字体**：`DM Mono`、`SF Mono`，用于技术编号、规格尺寸、坐标参数、时间戳与代码片段。
- **字号阶梯规范**：
  * 首屏巨标：`clamp(48px, 6.2vw, 92px)`
  * 区段主标：`clamp(28px, 3.2vw, 48px)`
  * 中文正文与功能标签：统一不小于 `12px`，保障移动端与读屏设备的可用性。

排版层级：

| 内容 | 当前规格 | 使用方式 |
| --- | --- | --- |
| 入口页主标题 | `clamp(42px, 5.2vw, 76px)`，字重 700 | 两行短句，第二行使用冰蓝强调 |
| 门户页 Hero 标题 | `clamp(36px, 4.3vw, 56px)`，字重 800 | 只强调一句核心价值，避免长段落 |
| 门户区块标题 | `18px` | 与右侧“查看全部”等文字动作同一行 |
| 正文 | `14px` 左右 | 颜色使用 `--text-secondary`，行高约 `1.75` |
| Eyebrow / 数据标签 | `10px` 左右，`DM Mono` | 全大写、增加字间距，表达模块上下文 |
| 卡片辅助信息 | `9px - 11px` | 用于日期、人数、技术栈和状态 |

中文标题的字间距使用轻微负值，让大字号更紧凑；不要为英文标签使用过大的字重。数字、日期、届次和技术术语尽量使用等宽字体，形成“知识日志”的感觉。

## 布局和空间

### 入口页

- 页面最小高度为 `100svh`，内容不包在传统卡片中，照片和叠层占满首屏。
- 顶部品牌栏使用 `padding: 29px clamp(24px, 5.5vw, 88px)`，左侧是校徽和双行品牌名，右侧是 `CS CLUB · 2026` 与中英语言切换。
- 主内容最大宽度约 `1340px`，桌面端为接近一半的文字列和一半的可视化列，网格比例约 `.98fr / 1.02fr`。
- 标题、说明和两组事实数字位于左侧；右侧是以“计算机科技小组”为中心的轨道网络。
- 底部左侧保留学校官网入口；底部中央可放置在线状态；底部操作使用向下箭头进入 `/tools`。

### 门户页

- 主内容最大宽度为 `1540px`，桌面端外围留白约 `28px`。
- 顶部导航高度约 `70px`，采用吸顶、半透明背景和细底边框。
- Hero 最小高度约 `300px`，左侧是标题和行动按钮，右侧是校园抽象图、网格、建筑、`RAG / API / OS` 信号节点和实时知识新增数字。

## 组件语言

### 品牌和导航

- 校徽使用圆形裁切资源 `college-logo-cropped.png`，不要用抽象图标替代学校识别资产。
- 品牌文字为中文校名 + 小字号英文或社团副标题，副标题使用 `DM Mono` 并增加字间距。
- 顶部导航使用 Lucide 图标和短中文标签，当前项用蓝色文字加底部 2px 指示线。
- 搜索入口是窄的输入触发器，保留 `⌘K` 提示；主题切换和移动菜单使用图标按钮。

### 入口页知识网络

这是首页最具识别性的签名元素，必须保留以下关系：

- 中央圆形节点代表社团本身。
- 四个外部节点分别代表“学习路线”“项目库”“历届知识”“成员协作”。
- 节点之间由低对比度轨道和连接线相连，表达知识流动，不表达复杂的真实拓扑。
- 右下角代码状态卡使用等宽字体和绿色状态点，补充工程社区气质。

轨道应该是环境的一部分，线条保持低透明度和细宽度；不要把可视化做成高对比度、发光过度的科技 HUD。

### 门户面板和列表

- 区块标题采用“等宽 Eyebrow + 中文标题 + 右侧文本动作”的结构。
- 公告、方向和最近更新使用列表式信息密度，行间以细分隔线维持扫描节奏。
- 标签使用 `6px` 左右圆角和浅色语义底，不使用高饱和实心胶囊堆叠。
- 项目卡由视觉头图、状态/年份、标题、简介、技术栈和人数/星标组成；头图可使用几何纹理、图标和短代码，不依赖额外照片。
- 成长卡用大号等宽数字、语义色图标和一条很弱的圆形装饰，数字优先于装饰。
- 名言卡使用低对比度蓝灰渐变和衬线体，与工程信息形成节奏变化，但不应成为营销式引语。

## 动效和交互

动效的角色是让“知识持续发生”可被感知，而不是让页面持续抢注意力。

| 位置 | 动效 | 规则 |
| --- | --- | --- |
| 入口背景 | 粒子、星点、连线 | 使用 Canvas；指针靠近时产生轻微吸引，按住拖动时产生粒子 burst |
| 入口节点 | 低幅漂浮 | 只保持缓慢的状态感，不做大幅位移 |
| 入口箭头 | 轻微上下 bounce | 引导进入 `/tools`，应在移动端保留 |
| 页面切换 | `opacity` + 约 `5px` 垂直位移 | 用于路由切换，时间约 `.18s` |
| 项目卡 | hover 上移约 `3px` | 同时加强边框和阴影，键盘聚焦也必须可见 |
| 按钮 | hover 上移约 `1px` | 主按钮颜色变深，次按钮增强边框 |

入口粒子在 `prefers-reduced-motion: reduce` 下只绘制一次，不持续请求动画帧。新增动效也应遵守同一策略。

交互路径：

- 入口页向下箭头进入 `#/tools`。
- 门户 Hero 的“开始学习之旅”进入 `#/learning`。
- “浏览项目库”进入 `#/projects`。
- 公告、推荐项目、小组方向和最近更新都使用明确的文本动作或可点击列表行。
- 所有图标按钮应有可读的 `aria-label` 或 `title`，图标本身不承担无法猜测的语义。

## 响应式规则

| 断点 | 规则 |
| --- | --- |
| `> 1240px` | 门户采用公告 / 推荐项目 / 右侧状态栏的三列布局，成长数据放在主区底部 |
| `<= 1240px` | 门户外层改为单列，右侧面板横向分成三列 |
| `<= 900px` | 顶部导航折叠为菜单；Hero 改为单列；门户主区单列；右侧面板两列，名言卡横跨整行 |
| `<= 760px` | 入口页改为纵向内容，隐藏非必要的届次和底部中心信息，可视化缩小为约 `335px` 高 |
| `<= 640px` | 门户列表和卡片进一步单列；推荐项目变为横向滚动卡；成长数据为两列；底部操作改为纵向排列 |

移动端必须优先保留：品牌识别、主标题、一个主要行动、知识网络中心节点和进入门户的箭头。次级状态文字、英文副标题和桌面导航可以隐藏，但不能挤压主要内容或造成横向溢出。

## 内容语气

- 主叙事围绕“学习、构建、分享、传承”，避免泛化的“领先、赋能、全方位”等营销词。
- 模块标签可以使用短英文上下文，如 `LIVE / CAMPUS`、`CURATED BY MEMBERS`、`KNOWLEDGE LOG`，但中文标题负责表达实际内容。
- 数字必须带有含义，例如“04 代成员持续共建”“68 个项目正在传承”，不要只展示孤立的增长数字。
- 行动按钮使用动词：“开始学习之旅”“浏览项目库”“查看全部”“了解风采”。

## 复用边界

### 应保持

- 真实校园照片作为品牌锚点。
- 深蓝入口页与浅色门户页的层级区分。
- 蓝色主行动色和多色语义点缀。
- 等宽技术标签、日期和数据。
- 细边框、小阴影、适度圆角和列表分隔线。
- “知识网络”作为首页可识别的视觉签名。

### 应避免

- 用新的紫色或深色渐变替代现有蓝色系统。
- 在所有区域同时使用蓝、紫、橙、绿和玫红，削弱语义关系。
- 将入口页做成普通营销 Hero，删除校园照片或中心知识节点。
- 将门户页做成无层次的卡片墙，忽略公告和项目的信息密度。
- 使用大面积模糊、过强发光、装饰性圆球或没有数据含义的数字。
- 新增没有明确操作结果的“了解更多”按钮。

## 维护清单

新增或调整首页相关组件时，按以下顺序检查：

1. 先判断内容属于入口叙事还是门户信息，不要跨层级复制表面样式。
2. 从现有令牌选择颜色，只有新增语义状态时才扩展色板。
3. 保持标题、Eyebrow、辅助文字和数据的既有层级。
4. 为桌面、`900px` 以下和 `640px` 以下布局分别确认内容顺序与可操作性。
5. 动效必须有 reduced-motion 行为，按钮和链接必须有清晰的 hover / focus 状态。
6. 需要新增图像时，优先选择能说明校园、成员、项目或实际状态的素材，不使用纯氛围图替代信息。
